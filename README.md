A program that writes one single-line office joke to `/output/entry.txt` — an entry for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty, $2 in USDC.

The joke:

> I finally got my inbox to zero, so Outlook scheduled a meeting called 'Inbox Zero' to celebrate it.

The setup is a small victory every office worker recognises: inbox zero, finally reached. The punchline is what Outlook does with it — it schedules a meeting called 'Inbox Zero' to celebrate, so the app marks the achievement by creating the very thing the worker just escaped: another meeting.

## Run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt` (99 characters, under the 200-character limit). Run it twice and the two files are byte-identical.
